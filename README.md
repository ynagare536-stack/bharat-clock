# Bharat Clock 🇮🇳

A simple and responsive digital clock built with **React + Vite** that displays the current time in India (Indian Standard Time).

## ✨ Features

- 🕐 Displays the current Indian Standard Time (IST)
- 📅 Displays the current date
- 🇮🇳 Uses the `Asia/Kolkata` timezone
- 📱 Responsive design
- ⚛️ Built with React
- ⚡ Powered by Vite

## 🛠️ Technologies Used

- React
- Vite
- JavaScript
- HTML
- CSS

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/ynagare536-stack/bharat-clock.git
```

Go to the project folder:

```bash
cd bharat-clock
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL shown in the terminal, usually:

```text
http://localhost:5173/
```
